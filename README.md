# Playwright AI Demo - SauceDemo E2E Test Otomasyonu

Bu proje, Playwright MCP ve yapay zeka ajanları kullanılarak SauceDemo e-ticaret uygulaması için oluşturulmuş uçtan uca test otomasyonu çalışmasıdır.

## Proje İçeriği
- `specs/saucedemo-test-plan.md`: Giriş, ürün sıralama, sepet ve ödeme adımları için test planı
- `tests/saucedemo.spec.ts`: Playwright TypeScript ile yazılmış bağımsız E2E test senaryoları

## Kurulum ve Çalıştırma
```bash
npm install
npx playwright test
```
